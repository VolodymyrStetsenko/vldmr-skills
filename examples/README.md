# Examples — real runs on real protocols

Every file in this folder is the **unedited output** of the skills' scripts,
run against public open-source protocols. Nothing here is fabricated or
hand-written — each `.md` report and `.json` payload was generated by the
command shown below, and each heuristic lead was manually spot-checked against
the source before being kept.

## What was run

```bash
# zk-circuit-review
python3 zk-circuit-review/scripts/enumerate_circuit.py <circuits-dir> \
    --json out.json --report report.md

python3 verifier-bridge-audit/scripts/scan_verifier.py <contracts-dir> \
    --json out.json --report report.md

    --json out.json --report report.md
```

## What these runs improved

Testing against real code exposed two false positives, both fixed and
regression-tested before these reports were generated:

1. **zk-circuit-review** — the `<--` witness-target extractor picked the loop
   variable in single-line `for` loops (`for (i=0; …) out[i] <-- x`), wrongly
   flagging `sha256compression.circom`. The target is now extracted with an
   operator-adjacent pattern, and `out` is correctly seen as constrained by the
   later `===` equations.
2. **evm-invariant-scan** — `reinitializer(…)` and inline
   `msg.sender` checks (`if (msg.sender != x) revert…`, Uniswap v4 style) are
   now treated as access control, removing false `permissionless-config-setter`
   and `initializer-not-guarded` flags on World ID and v4-core.

All planted-bug fixtures still flag 100% of their planted issues after these
changes (see `*/scripts/fixtures/`).
